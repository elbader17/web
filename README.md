# Eduardo Bader — Personal Site

Static personal site for [elbader17.github.io](https://elbader17.github.io). Single-page, dark cyber-minimalist design, served from GitHub Pages.

## Stack

- **HTML**: `index.html` (single page, 5 sections)
- **CSS**: Tailwind 3 (static, minified, **inlined** in `<style>` tag inside `<head>`)
- **Icons**: 23 inline SVG icons as `<symbol>` sprite referenced via `<use href="#i-name">`
- **JS**: `assets/js/main.js` (deferred) — terminal typewriter, scroll reveal, counters, parallax
- **Fonts**: Inter (body), Space Grotesk (display), JetBrains Mono (mono) — Google Fonts via `<link rel="preload" as="style">`
- **Images**: `yo.webp` (optimized), `og.jpg` (Open Graph)
- **SEO**: Open Graph, Twitter Card, JSON-LD (`schema.org/Person`), `robots.txt`, `sitemap.xml`

## File layout

```
myweb/
├── index.html              # Entry point — CSS inlined, SVG sprite inline, OG meta, JSON-LD
├── favicon.svg / .ico      # Favicons (SVG + 32×32 PNG ICO)
├── og.jpg                  # 1200×630 Open Graph image
├── yo.webp / yo.jpg        # Portrait (webp + jpg fallback)
├── robots.txt              # /sitemap.xml hint
├── sitemap.xml             # Single-URL sitemap
├── package.json            # Build scripts (npm run build / serve / lighthouse)
├── tailwind.config.js      # Theme tokens, custom shortcuts (@layer components)
├── src/
│   └── input.css           # Tailwind directives + custom component classes
├── assets/
│   ├── css/
│   │   ├── tw.css          # Generated by `npm run build:css`
│   │   └── style.css       # Custom animations, terminal, gradients, scroll-reveal
│   └── js/
│       └── main.js         # Deferred client-side logic
└── scripts/
    ├── inline_css.py       # Injects CSS into <head> of index.html
    └── replace_icons.py    # Replaces <i data-lucide="X"> with <svg><use/></svg>
```

## Develop / build / serve

```bash
npm install            # one-time
npm run build          # regenerate tw.css + inline it into index.html
npm run serve          # python3 -m http.server 8765
```

Open `http://localhost:8765`.

## How to update

### Edit content
All content lives in `index.html`. Sections are clearly commented:
- `<!-- HERO -->`
- `<!-- ABOUT -->`
- `<!-- SKILLS -->`
- `<!-- EXPERIENCE -->`
- `<!-- PROJECTS -->`
- `<!-- CTA / FOOTER -->`

### Change colors / theme
Edit `tailwind.config.js`:
```js
colors: {
  zinc: { ... },     // neutral background tones
  emerald: { ... },  // accent
}
```

### Add / remove an icon
The sprite is at the top of `<body>` in `index.html` (the `<svg style="position:absolute;width:0;..." aria-hidden="true">…`). Add a `<symbol id="i-name" viewBox="0 0 24 24">…</symbol>` and reference it with `<svg><use href="#i-name"/></svg>`.

### Change Tailwind classes / component shortcuts
Edit `src/input.css` (the `@layer components` block has `.btn-cyber-primary`, `.panel-card`, `.skill-chip`, `.nav-link`, etc.), then run `npm run build`.

### Regenerate favicon
```bash
python3 assets/build_favicon.py
```

## Notes

- All asset paths are **relative** (`./assets/...`, `./yo.webp`) so the site works at the repo root.
- No build step is required to **deploy** — `index.html` is self-contained. The build step is only needed when you change Tailwind classes or the component layer.
- The `<style>` block inside `<head>` contains all CSS (~31KB minified) — no external CSS request.
- `<script>` uses `defer` so it never blocks parsing.
- Google Fonts CSS is loaded non-blocking via `<link rel="preload" as="style" onload="...">`.
